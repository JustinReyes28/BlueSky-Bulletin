# BlueSky Bulletin | Your AI-Powered Weather Companion

BlueSky Bulletin is an intelligent weather application that combines real-time weather data with AI-generated insights to provide personalized, actionable weather information. Built with Next.js and powered by Mistral AI, BlueSky delivers weather updates that actually help you plan your day.

## ✦ What Makes BlueSky Special

- **AI-Powered Weather Insights:**
  - **Smart Summaries:** Get concise, human-readable weather briefings generated by AI
  - **Personalized Recommendations:** AI suggests activities and preparations based on current and forecasted weather
  - **Contextual Alerts:** Receive intelligent warnings about significant weather changes

- **Interactive Features:**
  - **Real-time Weather Map:** Visualize weather conditions on an interactive Leaflet.js map
  - **Location Flexibility:** Search for any location or use automatic geolocation detection
  - **AI Chat Interface:** Ask weather-related questions and get intelligent responses

- **Performance & Privacy:**
  - **Blazing Fast:** Smart caching with Upstash Redis ensures quick responses
  - **Privacy-First:** No personal data storage - completely stateless design
  - **Cost-Efficient:** Optimized API calls with intelligent caching strategies

## ✦ Intelligent Caching System

BlueSky uses a sophisticated caching strategy to maximize performance and minimize costs:

- **Weather Data:** Cached for 30 minutes with ~10km precision coordinate rounding
- **AI Insights:** Cached for 8 hours to reduce Mistral API calls
- **Smart Rate Limiting:** 30 requests per minute per IP to prevent abuse
- **Graceful Fallback:** Automatic fallback to memory cache if Upstash is unavailable

Check out [Caching.md](Caching.md) for all the technical details.

## ✦ Getting Started

### What You'll Need

- Node.js 18.17 or newer
- A Mistral API key (get one [here](https://mistral.ai/))
- An Upstash Redis database (free tier available)
- Vercel account for deployment (optional)

### Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/bluesky-bulletin.git
   cd bluesky-bulletin
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up your environment variables:**
   Create a `.env.local` file and add:
   ```env
   MISTRAL_API_KEY=your_mistral_key_here
   KV_REST_API_URL=your_upstash_redis_url
   KV_REST_API_TOKEN=your_upstash_redis_token
   NEXT_PUBLIC_APP_URL=http://localhost:3000
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

Now open [http://localhost:3000](http://localhost:3000) in your browser and experience BlueSky Bulletin!

## ✦ Project Architecture

- `/app`: Next.js pages and API routes
  - `page.tsx`: Main dashboard with weather and AI components
  - `api/weather/route.ts`: Weather data API with caching
  - `api/insights/route.ts`: AI insights generation endpoint
  - `api/insights/chat/route.ts`: Interactive AI chat interface

- `/components`: Reusable UI components
  - `ai-insights/`: AI-generated weather insights display
  - `map/`: Interactive weather map with Leaflet
  - `search/`: Location search functionality
  - `weather/`: Weather data visualization components

- `/lib`: Core application logic
  - `ai/`: AI integration and prompt engineering
  - `cache/`: Upstash Redis caching implementation
  - `hooks/`: Custom React hooks for data fetching
  - `weather/`: Weather data processing and utilities
  - `validation/`: Input validation with Zod schemas

- `/public`: Static assets and images
